# Haxball Radar Client

The Haxball Radar desktop client for HaxBall: FC-style HUD, match commentary, stadium crowds,
player cards from [haxballradar.com](https://haxballradar.com), club match-ups, voice chat and more.

## Download

Get the latest version from **[Releases](../../releases/latest)**: download `HaxballRadar-<version>.zip`,
unzip it anywhere and run `Haxball Radar.exe`. The client updates itself after that.

Windows 10/11 only.

This repository hosts the release downloads; the website is [haxballradar.com](https://haxballradar.com).
